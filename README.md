# perf-evidence

This branch holds only the evidence images (charts) linked from the bodies of
my upstream performance and reliability pull requests to
[pingdotgg/t3code](https://github.com/pingdotgg/t3code). It has no code and no
shared history with the project, and it is never part of a pull request.

Images live under `prs/<pr>/<file>.png`. Files are only added, never rewritten,
so the links in pull request bodies keep working.
